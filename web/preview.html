Tacit.Results

Obsługa błędów bez wyjątków: Result<T> z czytelnym modelem błędów.

Każda operacja zwraca sukces albo nazwany błąd (walidacja, brak zasobu, konflikt). Kod wywołujący widzi wszystkie ścieżki w sygnaturze i składa je w potoki zamiast łapać wyjątki. Szczegóły w przewodniku po obsłudze błędów.

Instalacja

dotnet add package Tacit.Results

var result = await orders.FindAsync(id)
    .Ensure(o => o.CanBeCancelled, Error.Conflict("order.locked"))
    .Map(o => o.Cancel());

return result.Match(Results.Ok, error => error.ToProblem());
